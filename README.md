# 🎬 Catálogo de Filmes

Uma aplicação web desenvolvida com **React**, voltada à exibição e organização de informações sobre filmes.

## 📌 Sobre o projeto

O Catálogo de Filmes é um projeto de desenvolvimento frontend criado para praticar conceitos do React e construir interfaces dinâmicas para apresentar conteúdo relacionado ao universo cinematográfico.

O projeto faz parte da minha jornada de aprendizado em desenvolvimento web e da construção do meu portfólio como desenvolvedor.

## 🛠️ Tecnologias

- **React** — construção de interfaces.
- **JavaScript** — implementação da lógica da aplicação.
- **HTML5** — estruturação do conteúdo.
- **CSS3** — estilização da interface.

## ⚙️ Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- npm instalado.

### 1. Clone o repositório

```bash
git clone https://github.com/V1NGU3R/catalogo_filmes.git
```

### 2. Acesse a pasta

```bash
cd catalogo_filmes
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute a aplicação

Utilize o comando de desenvolvimento configurado no `package.json` do projeto.

Se estiver utilizando Vite:

```bash
npm run dev
```

Se estiver utilizando outra ferramenta, consulte os scripts disponíveis no `package.json`.
